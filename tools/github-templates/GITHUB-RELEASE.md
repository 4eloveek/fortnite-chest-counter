# GitHub: исходники и программа

Полная инструкция — [../UPLOAD-GITHUB.md](../UPLOAD-GITHUB.md).

Исходники этой папки можно загрузить в Git. Готовый **`{{EXE}}`** находится
в корне комплекта и исключён `.gitignore`; прикрепите его отдельно к
**GitHub Releases** с тегом **v{{VERSION}}**. Пользователю нужен только этот EXE.

Размер файла: **{{BYTES}} байт**. SHA256:

```text
{{SHA256}}  {{EXE}}
```

Внутри runtime, OCR, обе модели и лицензии, включая MIT самого приложения.
Они автоматически извлекаются в приватный временный кэш. Пользовательские
данные остаются в LOCALAPPDATA. EXE не подписан; на новом ПК может потребоваться
официальный Visual C++ Redistributable x64. Личные данные не включены в комплект.
