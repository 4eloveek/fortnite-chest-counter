# Примеры для OCR

Личные игровые кадры первоначального пользователя в GitHub-комплект не включены.
Для исправления OCR можно добавить собственные обезличенные фрагменты с XP и
названием сундука: уберите никнеймы, чат и другие личные сведения.

Укажите язык, разрешение/HUD, тип уведомления, исходный и распознанный текст,
настройки фильтра, требование XP и ожидаемое изменение счётчика. Нужны также
отрицательные примеры: задания, посторонний XP и экран без открытого сундука.
Файлы примеров по умолчанию исключены из Git; публикуйте их только осознанно.
