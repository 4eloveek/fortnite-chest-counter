# Контекст проекта

Fortnite Chest Counter 0.2.0 — отдельное Windows x64 приложение для подсчёта
экранных уведомлений об открытии сундуков. C# / .NET 10 / Windows Forms / Tesseract 5.2.0.

Реализованы выбор области, OCR rus/eng, проверка XP рядом с названием сундука,
защита от повторов, счётчики матча/дня/всех открытий, ручные поправки, глобальные
клавиши, прозрачный для кликов оверлей, JSON-история и дневной столбчатый график.
Периоды графика: 7/30 дней, текущий месяц, всё время и произвольные даты.

Программа не получает внутриигровой журнал. Быстрые открытия со слившимися
уведомлениями могут считаться одним; точность нужно проверять в конкретном режиме.
Новый матч отмечается вручную. Пользовательские данные лежат в LOCALAPPDATA,
не включаются в Git и сохраняются между обновлениями приложения.

Обычная папочная сборка создаётся в `dist`; однофайловая — в `release`.
Один EXE включает runtime/модели/лицензии и извлекает их в приватный временный кэш.
Нативный CoreCLR встроен в singlefilehost. Trimming отключён; при смене SDK
режим `IncludeAllContentForSelfExtract` и загрузку Tesseract проверять заново.

Архитектура: `DESIGN-DECISIONS.md`; диагностика: `TROUBLESHOOTING.md`;
проверки: `VERIFICATION.md`; GitHub: `../UPLOAD-GITHUB.md`.
