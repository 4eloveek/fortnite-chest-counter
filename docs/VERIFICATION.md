# Проверки версии 0.2.0

- На Windows с .NET SDK 10.0.404 прошли **73 теста Core**: классификатор,
  защита от повторов, JSON, восстановление, смена дат и дневная статистика.
- Опубликованные DLL прошли 23 условия захвата/OCR: GDI и освобождение ресурсов,
  18 синтетических положительных примеров и 2 отрицательных. Это не игровой матч.
- График ранее проверен 36 UI-условиями при DPI 96, включая периоды, обновление,
  нулевые дни, прокрутку и закрытие окон.
- Один EXE проверялся с кириллицей/пробелами, переименованием, без соседних DLL,
  с запрещённым поиском установленного .NET и на первом/повторном запуске.
  Проверены модели, native OCR, GDI, лицензии, fixture JSON и offscreen-отрисовка UI.
  Контрольный настоящий PNG также распознан локально; личный кадр в репозиторий не включён.

`tools/verify-release.ps1` и `tools/verify-release` содержат код повторяемой
проверки. Внешний startup hook исполняется в готовом EXE до Main, проверяет
извлечённое содержимое и завершает только собственный процесс. Приложение не
читает и не изменяет настоящий state.json в этом режиме. Сам hook не часть EXE.
Тестовые окна выводятся за пределами рабочего стола без смены активного окна.
Для дополнительного кадра можно передать `-Sample` с собственным обезличенным PNG.

Отчёты создаются в локальной `diagnostics` и исключаются из Git. Частные кадры,
системные отчёты, настройки и история первоначального пользователя не публикуются.
Проверки не доказывают точность всех игровых режимов, физических клавиш, других
Windows/DPI или отсутствие пропусков при любых быстрых открытиях. На проверявшемся
Windows-ПК Visual C++ Runtime уже установлен; его отсутствие отдельно не тестировалось.
