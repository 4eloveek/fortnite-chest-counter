`BitBlt` с `SRCCOPY | CAPTUREBLT`, проверкой результата и освобождением DC
в `finally`. `Core`, формат JSON, статистика и пороги OCR не менялись.

Исправленный метод и его нативные объявления отдельно скомпилированы компилятором

- снимки рабочего стола не сохранялись; в отчёте только результаты проверки.

Это проверка исправленного механизма GDI, **не сборка проекта SDK .NET 10**
и не повторный запуск обновлённого приложения. Результаты — в `capture-fix-smoke.txt`.

### Воспроизведение

Без фильтра правильное ОП читалось всего с 11% уверенности, ниже порога 20%.
Ни один из 54 исходных диагностических вариантов не прошёл обе проверки.
Увеличение масштаба и другие PSM не дали лучшего основания менять OCR-подготовку.

и `console.txt`. Подготовленные изображения и отдельный фрагмент подписи сохранены
только для диагностики; они не заменяют оригинальный PNG.
