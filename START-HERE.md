# Весь проект в одной папке

Эту папку можно целиком перенести на Windows. В ней находятся готовая программа,
исходники, OCR-модели, пакеты зависимостей, тесты и документация для доработки.

## Начать работу

| Файл | Для чего |
| --- | --- |
| `Run.cmd` | Запустить готовый счётчик |
| `Build.cmd` | Проверить тесты, пересобрать программу и архивы |
| `tools/build-release.ps1` | Собрать один EXE для GitHub отдельно от `dist` |
| `Test.cmd` | Запустить тесты отдельно |
| `Diagnostics.cmd` | Сохранить отчёт о системе, файлах и настройках в `diagnostics` |
| `Package.cmd` | Собрать ZIP со всем проектом после своих изменений |
| `FortniteChestCounter.sln` | Открыть исходники в IDE |

Для **запуска** используйте `Run.cmd`. Для **изменения кода и сборки** установите
[.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0).
Исходный комплект проверен с SDK **10.0.402** на Linux; текущая версия
**0.3.1** исправляет пропуск одиночных сундуков, который давала жёсткая
сетка подписи в 0.3.0. Windows-проект компилируется, 90 тестов Core проходят
на Linux. Пользователь проверил исправленную сборку в игре и сообщил, что она
работает; количественная точность и серия быстрых открытий не измерялись.
Windows PowerShell 5.1, которым пользуются CMD-файлы, входит в Windows 10/11.

Настройка игры и горячие клавиши описаны в [README.md](README.md).
Актуальный сохранённый статус и следующий шаг — в [AGENTS.md](AGENTS.md):
селектор и Ctrl+Alt+F7 проверены пользователем на рабочем столе; первая живая
серия дала +5 на пять открытий. Общая точность, повторы и быстрые открытия
всё ещё требуют проверки. В 0.2.0 добавлена кнопка «Статистика по дням»,
в 0.3.0 — настройка клавиши «+1», в 0.3.1 — исправление одиночных сундуков.

Отдельный однофайловый релиз: `release/v0.3.1-win-x64/FortniteChestCounter-v0.3.1-win-x64.exe`.
Опубликованный выпуск: https://github.com/4eloveek/fortnite-chest-counter/releases/tag/v0.3.1.
Для распространения нужен только этот EXE. Как загрузить его в GitHub Releases
и повторить сборку: [docs/GITHUB-RELEASE.md](docs/GITHUB-RELEASE.md).

## Если что-то не работает

1. Откройте [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) и найдите симптом.
2. Запустите `Diagnostics.cmd`: он создаст папку с отчётом и копиями JSON-данных,
   если они уже существуют на этом Windows-ПК.
3. Для ошибок распознавания сохраните кадр с начислением XP в `assets/samples`
   и запишите, что видно в поле диагностики программы.
4. Для работы с кодом начните с [docs/WINDOWS-DEVELOPMENT.md](docs/WINDOWS-DEVELOPMENT.md).

Для продолжения с ИИ-помощником достаточно открыть эту папку и попросить прочитать
`AGENTS.md`, `docs/PROJECT-CONTEXT.md` и `docs/DESIGN-DECISIONS.md`.
