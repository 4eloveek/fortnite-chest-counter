# Комплект для GitHub

В этой папке находятся исходники и готовый EXE версии 0.2.0.

| Что | Где |
| --- | --- |
| Запустить программу | `FortniteChestCounter-v0.2.0-win-x64.exe` или `Run.cmd` |
| Основная инструкция | `README.md` |
| Выгрузка в GitHub | `UPLOAD-GITHUB.md` |
| Исходники | `src` и `FortniteChestCounter.sln` |
| Тесты | `tests` |
| Модели и лицензии | `assets/tessdata`, `assets/licenses`, `LICENSE` |
| Собрать один EXE | `tools/build-release.ps1` |
| Собрать папочную версию | `Build.cmd` |
| Проверить готовый EXE | `tools/verify-release.ps1` |

Для запуска .NET SDK не нужен. Для сборки установите **.NET SDK 10**.
Готовый EXE — отдельный asset для GitHub Releases, а не файл исходников в Git.
Соседние исходники не нужны программе для работы: переносить можно только EXE.

Локальные NuGet-пакеты включены для офлайн-сборки. Они не попадут в Git благодаря
`.gitignore`; после клонирования пакетные зависимости скачиваются с nuget.org.
Личные JSON, игровые кадры и записи, диагностика и промежуточные сборки в комплект
не включены. Реальная статистика уже установленной программы не изменяется.
